# DRAW code review and optimization record — 2026-09-07

## Result and scope

The main editor received a small, behavior-tested cleanup. Baseline commit `b0c4332` is preserved as `baseline-pencil-verified-2026-09-07`; the cleaned revision is tagged `cleanup-reviewed-2026-09-07`. Both are stored in the independent `H:\draw-git` clone. The live Vercel copy remains the user-tested baseline; this review does not redeploy it.

DRAW has **no hosted backend**. The 4,600-line main HTML file contains the document model, Canvas renderer, input handling, persistence, parsers, export and optional Entity model client. Paper.js runs locally for Boolean geometry and SVG imports. The model service is external and was not reviewed here. Review effort focused on the active editor; the separate Vectoriser received a limited source inspection, and the old Gemini draft is archival, not a second supported implementation.

CodeGraph tools were unavailable in this session; findings came from direct source inspection and browser outcomes. This is not an exhaustive security audit or a claim of globally optimal performance.

## Changes made

| Finding | Before | After |
|---|---|---|
| Duplicate Undo snapshots | `snapshot()` called `clonePath()`, deep-copying anchors and creating fresh IDs. Two snapshots of an unchanged rectangle differed. A no-op history push consumed Undo, leaving 1 path. | Serialize existing geometry directly, omitting transient path IDs. Snapshot strings are stable; no-op push followed by Undo leaves 0 paths. Redo survives a no-op push after Undo. |
| Repeated pressure averaging | Every width read reduced the full pressure array; retained storage grew with the stroke. | Maintain a sum and count at the existing sample points. Width reads and pressure bookkeeping storage are constant-size. Geometry samples are still retained for simplification. |
| Shortcuts escape form fields | ArrowRight in URL/password fields moved the selected anchor, and `n` changed the tool. | All input/select/textarea and content-editable targets retain their own keyboard handling. Tested anchor x stays 100 and mode stays Direct Select; canvas ArrowRight still moves x by 1. |
| Inconsistent default fill-rule shape | Newly created paths acquired an explicit default fill rule only after cloning. | Initialize `fillRule: 'nonzero'` at path creation, keeping snapshot structure stable through restore. |

The cleanup preserves input sampling, pressure response, smoothing, rendering timing, geometry algorithms, document format and the accepted Apple Pencil eraser-end limitation. It adds no brush or eraser feature.

## Verification

All 10 scripts passed: `review_cleanup.py`, `apple_pencil.py`, `pencil.py`, `rulers.py`, `snapping.py`, `precision.py`, `pathfinder.py`, `artboards.py`, `png_drop.py`, and `entity_panel.py --offline`.

Coverage includes actual document/selection/camera outcomes, Undo/Redo, synthetic pen pressure, palm exclusion, import atomicity, exported PNG/SVG pixels, compound holes, persistence and model-preview isolation. Model-panel checks used fixtures; no new live model-service verification was performed. The cleaned version has not had a new physical iPad test. Browser regression screenshots were regenerated by the existing tests.

Outcome-debug triage: the keyboard symptom was reproduced as a routing error, not failed drawing state. The same ArrowRight input moved an anchor normally with canvas focus. After the narrow guard change, it still does so, while editing the URL and key fields no longer changes artwork. Runtime access used `window.__DRAW__` and existing global functions; no framework scans.

## Prioritized next improvements

These are recommendations from the inspected code, **not changes already implemented**. Validate each in its own commit and keep only improvements supported by measurements and outcomes.

| Priority | Candidate and source | Expected benefit / implementation constraint | Acceptance measurement |
|---|---|---|---|
| 1 — correctness | Unify validation for JSON, bare path data and SVG (`normalizeLoadedPaths`, `loadOutline`, `parsePayload`). JSON camera data is assigned without finite/range checks; styles and anchor values are weaker than the SVG route. Bare path input uses the legacy parser, whose arc branch skips arc parameters and connects endpoints. SVG export interpolates imported color values. | Validate finite bounded coordinates/camera, supported color values, shape/anchor counts and path commands **before document mutation**; route bare paths through the validated geometry parser or reject unsupported commands. Preserve legacy valid documents and escape serialized attributes. This reduces malformed-input hangs, silent geometry changes and unsafe exported attributes. These concerns were identified by source inspection, not an exploit test. | Invalid inputs return promptly without document/camera/history changes; valid legacy and compound files round-trip; arcs match the SVG import route. |
| 2 — responsiveness | Schedule drawing once per animation frame; cache static board/grid layers (`draw`, pointer-move handlers, `drawArtboard`, `drawGrid`). Current interactions redraw the full scene synchronously, sometimes more than once per action. | Retain every geometry/pressure sample while coalescing paint requests. Separate static background, artwork and transient interaction graphics. Do not delay pointer-up commits, exports or test state. [Canvas optimization guidance](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Optimizing_canvas) supports offscreen caching; [requestAnimationFrame](https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame) follows display refresh. | Record p50/p95 frame times, long tasks and stroke latency on M1 iPad with 1k/10k/20k anchors; identical final paths and export pixels. |
| 3 — responsiveness | Cache bounds/Path2D and narrow hit-testing candidates (`hitPathAt`, `hitStrokeAt`, `closestSegmentOnPath`). Empty-space hits may scan all paths and repeatedly evaluate cubic samples. | First reject distant bounding boxes expanded by hit tolerance, then test relevant paths in existing front-to-back order. Add a spatial index only after profiling; invalidate caches on all geometry changes, Undo and load. | Lower p95 pointer-hit time on large scenes with identical hit results at zoom extremes, on curves, holes, locked/hidden paths and overlapping paths. |
| 4 — storage reliability | Move artwork autosave from synchronous `localStorage` to IndexedDB (`persistSession`), and surface storage failures. Current save is debounced 250 ms, but serializes the full document and silently catches failures. | Keep small preferences in localStorage; persist document revisions asynchronously with migration and last-good-save tracking. Handle storage quota and tab closure; never claim a failed save succeeded. [Web Storage is synchronous](https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API); [IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API) is suited to larger structured data. | Main-thread save time, restore correctness, quota-failure UI and crash/reload recovery for large documents. |
| 5 — memory | Replace the 80 full-document history strings with a byte-budgeted history or commands plus periodic snapshots (`pushHistory`). | The deduplication fix helps now, but every distinct edit still stores the whole document. Start with measured byte limits; command history requires careful grouping and transactional import/Boolean behavior. | Peak history memory and Undo latency over 100 edits; same user-visible grouping, Redo branching and all existing history tests. |
| 6 — heavy geometry | Profile and potentially move simplification/Boolean operations into a worker (`simplifyPencil`, `booleanSelection`). | Worker startup, data copying and result reconciliation may outweigh gains for small shapes. Keep synchronous fast paths until measurements justify workers; apply results only to the matching document revision. | Longest main-thread task and total operation latency for worst-case curves; atomic cancellation and unchanged geometry/areas. |
| 7 — model integration | Bound response sizes and validate response structure before large parsing work (`entityFetch`, `entityModel`). The client currently buffers `response.json()` before its downstream SVG size checks. | Add explicit client response limits and diagnostics. If hosted inference is later required, design a separate authenticated proxy with secret handling, quotas and cancellation; the existing browser-only tool does not require one. | Oversized/malformed/timeout responses recover without changing the document or preview; real service round trip in addition to fixtures. |
| 8 — maintenance | Extract document/persistence/geometry logic into small modules after stabilizing boundaries. Cache frequently reused UI references. | Easier independent tests and safer optimization experiments. Avoid a framework migration solely for file size: it adds deployment/runtime complexity without a demonstrated drawing benefit. Preserve simple static hosting and the chosen local-file workflow. | Same regression suite, startup/network measurements and no new build requirement unless intentionally adopted. |

## Keeping the best version

Use `scripts/save_version.py` after validation to commit and synchronize the H: clone. Keep the hardware-verified baseline and each reviewed milestone as named tags. For larger experiments, use a branch and compare fixed documents plus device latency/memory measurements. A faster isolated function is insufficient if drawing fidelity or undo behavior regresses.
