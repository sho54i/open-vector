Text

Load a TTF, OTF or WOFF font, including Blender. Select inserted text to change its wording. Updating rebuilds its outlines at the current top-left; rotation and anchor edits are replaced. SVG exports keep outlines.

Pencil & touch

Touch the canvas with Pencil to see pressure.

Freehand Pencil: average pressure adjusts the whole stroke width. 0% keeps the base width; higher values make light strokes thinner and firm strokes thicker.

Higher smoothing reduces anchors. Selection reach enlarges Pencil hit targets without enlarging the artwork.

Battery: unavailable in this web app. Check the iPad Batteries widget. Barrel double-tap and squeeze are not supported here; use the on-screen tools.

Art filters

Stylized sketch grain, painted texture or repeating bubble impressions. One editable preset per path, applied before blur and shadow. Original anchors and colours stay editable.

Styles

Shadow and blur stay editable. Round straight corners on closed shapes, then use A to edit their Bézier handles. Roughen converts curves to editable anchors. Geometry operations can be undone; text becomes outlines. Release clipping before changing geometry.

Select visible, unlocked artwork.

Stroke width
POSITION %WIDTH %

Width is a percentage of stroke weight. Profiles follow each contour from its first anchor. Applying a profile uses a continuous stroke with round joins; choosing a dash restores uniform width.

Select paths to shape their stroke width. SVG exports the stroke as filled outlines.

Clipping mask

Select artwork and a closed shape above it. The topmost selected shape becomes the mask; its fill and stroke are hidden until released.

V selects and moves the mask with its artwork. A edits individual anchors. Ungroup ordinary groups before making a mask. Nested masks are not supported.

Reflect

Mirror the whole selection around its bounding-box centre, or choose a mirror line.

Handles and gradients mirror with paths. Reflected text becomes editable outlines.

Blend

Select two paths with V and Shift-click. Matching anchors and handles blend in path order; sources stay unchanged.

Draw, edit and save

Use K for Measure: click two anchors or drag a line to read distance and X/Y deltas in Document setup units. Hold Shift for 45° angles, Alt to measure from the centre, or both together. Escape clears the temporary measurement; artwork is unchanged.

Use P for Pen, N for Pencil, M for Rectangle and L for Ellipse. Click with Pen to add corners; drag to draw curves. Click the first anchor to close a path, or press Escape to finish an open path.

V selects objects; A edits anchors and handles. Long-press Pen for Add, Remove and Convert anchor. Convert: click to toggle smooth/corner, drag an anchor for mirrored handles, or drag a handle independently. Shift constrains angles.

Ctrl/Cmd+Z undoes; Ctrl/Cmd+Y redoes. Ctrl/Cmd+C and V copy and paste; Ctrl/Cmd+F pastes in front. Alt-drag copies selected artwork. Space-drag pans; Ctrl/Cmd+wheel zooms; Ctrl/Cmd+0 fits the active artboard.

File → Document setup changes board dimensions and document settings. Save outline JSON to retain editable recipes, artboards and styles. Export SVG or PNG for sharing. Tools shows hidden inspector panels; their title controls collapse, detach or dock them.

Generate with your model, or paste SVG

  1. Open Vector Assistant from Tools. In Model connection, enter an HTTP(S) API base ending in your service’s API prefix (often /v1). Enter a model ID, or Connect to discover models.
  2. Add an optional bearer API key. It stays in this tab’s memory and is cleared on reload. Endpoint, model, prompt and accepted preview are remembered in this browser.
  3. Describe the artwork and Generate. Review the separate preview; Insert adds independent editable paths centered on the active artboard. One Undo removes that insertion.

You can also Paste SVG, or open Vector source / manual paste, paste source and choose Preview source. No model connection is required. Editing source disables Insert until you preview it again.

Connection help

The service must implement Chat Completions with a text response and allow browser CORS requests from this editor. Connect uses /models; if model discovery is unsupported, enter the model ID and use Generate directly. Check the base URL, model and key for HTTP errors. An HTTPS editor may block an HTTP service: use a compatible HTTPS endpoint or run the editor locally. Cancel stops waiting; requests time out after three minutes.

Supported artwork

Flat-colour paths (M L H V C Q Z), rectangles, circles, ellipses, lines, polygons and polylines; up to 512 shapes and 10,000 anchors. Outline text and simplify transforms, gradients, arcs and filters before assistant import. Invalid artwork preserves the previous preview and document. The model gets your prompt, not your document or selection.

Connect a browser-capable agent

The editor exposes a versioned, provider-independent browser tool API. Use your browser automation’s page evaluation in the editor tab (or its frame). No model connection or additional server is needed. This is a browser API, not an MCP transport.

const api = window.__VECTOR_ASSISTANT__;
api.listTools();
await api.callTool('get_document', {});
await api.callTool('preview_svg', {svg: '<svg>…</svg>'});

Read the document revision and preview ID from the results before calling insert_preview. Insertion requires both current tokens and a unique requestId; retries with the same ID return the original result. All calls return {ok, result} or {ok:false, error}. Preview changes never edit the document. Insert is one Undo step. Export and read tools return data without downloading files.

Use Help → Agent tools to download the complete guide and live tool schemas. Your browser automation can expose these calls through its own MCP tools. API keys are never included in tool results.
